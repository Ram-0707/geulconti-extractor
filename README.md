# 글콘티 대사 추출기

워드(.docx) 글콘티에서 **대사만** 남기고 지문·연출 지시를 걷어내는 도구입니다.

### → [바로 쓰기](https://ram-0707.github.io/geulconti-extractor/)

## 쓰는 법

위 링크를 열면 바로 쓸 수 있습니다. 내려받아 `index.html`을 더블클릭해도 똑같이 동작합니다.
설치할 것도, 회원가입도 없습니다.

**올린 파일은 어디로도 전송되지 않습니다.** 워드 파일을 읽고 대사를 뽑는 일은 전부 여러분의
브라우저 안에서만 일어납니다. 서버로 보내는 코드가 아예 없습니다 — 링크를 연 뒤 인터넷을
끊어도 그대로 동작합니다.

글을 넣는 방법은 두 가지입니다.

**① 워드 파일 열기** — .docx 파일을 창에 끌어다 놓습니다 (여러 개 한꺼번에 가능)

**② 직접 붙여넣기** — 워드에서 글콘티를 복사해 붙여넣습니다. 붙여넣는 순간 바로 추출되고,
글을 고친 뒤 <kbd>Ctrl</kbd>+<kbd>Enter</kbd> 나 `대사 뽑기`로 다시 돌릴 수 있습니다.
표를 통째로 복사해도 칸 구분이 탭으로 살아 있어 대사 칸을 알아냅니다.
한 칸 안의 줄바꿈(Shift+Enter)은 대사가 쪼개지지 않도록 한 줄로 이어 붙입니다.
입력창에서 <kbd>Tab</kbd> 키를 누르면 칸 구분자(탭)가 그대로 입력됩니다.

넣고 나면 왼쪽에서 추출 결과를 확인하고, 틀린 줄은 체크를 풀거나 직접 고친 뒤
`결과 복사` / `.txt 저장` / `.docx 저장` 하면 됩니다.

## 추출 규칙

| 원본 | 결과 |
|---|---|
| `SD. 하준, 어깨를 늘어뜨린다. 하준 "에이… 또 틀렸잖아…"` | `에이… 또 틀렸잖아…` |
| `서윤(속)` ⇥ `(SD. 물음표 띄우는) 뭐, 뭐라고?` | `(SD. 물음표 띄우는) 뭐, 뭐라고?` |
| `넓은 정원. 햇살이 쏟아진다.` | (제외됨) |

- **따옴표 안 대사 뽑기** — 따옴표 안의 글만 남기고 밖의 지문은 버립니다.
  워드를 거치면 여는/닫는 따옴표 모양이 자주 어긋나므로(`”대사”`, `“대사“`, 전각 `＂대사＂`)
  짝을 따지지 않고 인식합니다. `" "` `“ ”` `〝 〞` `＂ ＂` `' '` `‘ ’` `「 」` `『 』` `《 》` `〈 〉` 모두 됩니다.
  큰따옴표 안에 든 작은따옴표(`“정말 ‘그것’이 맞아?”`)는 대사의 일부로 그대로 두고,
  영어 아포스트로피(`don't`)는 따옴표로 오인하지 않습니다.
  작은따옴표 대사(속마음)도 큰따옴표 대사와 **똑같이 뽑습니다.** 한 줄에 둘 다 있으면 둘 다 나옵니다.
  다만 괄호 안에 든 작은따옴표는 식자·연출 지시로 보고 따로 뽑지 않습니다
  (`(보조식자 '작게 넣기')` → 이 줄이 대사로 잡히면 지시문째 그대로 남습니다).
- **화자명 뒤(탭·표 칸) 대사 뽑기** — 표로 된 글콘티는 각 행의 마지막 칸을, 탭으로 나뉜 줄은 탭 뒤를 대사로 봅니다.
- 두 규칙 어디에도 걸리지 않는 줄(컷 번호, 배경 묘사 등)은 자동으로 빠집니다.

- **들여쓴 이어지는 줄도 대사로** — 한 대사가 두 줄에 걸쳐 있을 때 뒷줄을 살립니다.

  ```
  서윤(속) ⇥ 이 사람은 자기가 뭘 잘하는지 알고 있고,
               그걸 쓸 줄도 아는 것 같다. (보조식자 '작게 넣기')
  ```

  워드 파일에서는 **문단에 걸린 실제 들여쓰기 값**(문단 스타일에서 물려받은 것 포함)과
  한 문단 안의 줄바꿈(Shift+Enter)을 읽어서 판단합니다. 대사 바로 뒤에 오는 들여쓴 줄만
  이어지는 대사로 보므로, 들여쓰기만 같고 앞줄이 대사가 아니면 지문으로 남습니다.
  이렇게 이어 붙인 줄은 목록에 `⤷ 이어지는 줄`로 표시됩니다.

  붙여넣기 모드에서는 워드의 들여쓰기 설정이 평문 복사 과정에서 사라지므로
  **줄 앞의 탭이나 두 칸 이상 공백**만 단서로 씁니다. 그마저 없으면 자동으로는 알 수 없으니
  목록에서 그 줄의 체크를 켜주세요.

### 옵션

- **이어지는 줄 앞 대사에 붙이기** — 위에서 이어 붙인 줄을 앞 대사와 한 줄로 합칩니다.
  말풍선 하나당 한 줄로 글자 수를 세고 싶을 때 쓰세요. 기본은 꺼짐(원래 줄 나눔 유지).
- **두 칸 이상 띄어쓰기도 구분자로** — `나레이션    그렇게 봄이 지나갔다` 처럼 탭 대신 공백으로 정렬한 콘티용
- **화자명 함께 남기기** — `하준: 에이…` 형태로 출력
- **괄호 ( ) 안 지시문 지우기** — `(SD. 물음표 띄우는) 뭐라고?` → `뭐라고?`
- **빈 줄로 문단 나누기** — 대사가 끊긴 구간에 빈 줄을 넣어 컷 구분을 남깁니다

자동 추출이 100%일 수는 없어서, 왼쪽 목록에서 **줄마다 손볼 수 있게** 해뒀습니다.

- 체크를 **풀면** 그 줄이 결과에서 빠집니다.
- 자동으로 걸러진 줄의 체크를 **켜면** 그 줄이 결과에 더해집니다. 이때 원문이 편집칸에 채워지므로
  (표라면 마지막 칸, 아니면 줄 전체) 필요 없는 부분만 지우면 됩니다.
- 편집칸의 글자는 언제든 직접 고칠 수 있고, 손댄 줄은 옵션을 바꿔도 그대로 남습니다.

오른쪽 결과창도 그대로 편집 가능하고, 아래에 줄 수와 공백 제외 글자 수가 표시됩니다.

## 테스트 파일

동작 확인용 샘플입니다. 내용은 전부 지어낸 것입니다.

- `test/sample.docx` — 문단·표·탭·공백 정렬이 섞인 샘플
- `test/indent.docx` — 들여쓰기로 이어지는 대사가 든 샘플

## 기술 메모

외부 라이브러리 없이 단일 HTML 파일입니다. .docx(=ZIP) 해제는 브라우저 내장
`DecompressionStream('deflate-raw')`, .docx 생성은 무압축(STORE) ZIP 직접 조립으로 처리합니다.
워드의 들여쓰기는 `w:ind`와 `styles.xml`의 문단 스타일(`basedOn` 상속 포함)에서 읽습니다.
